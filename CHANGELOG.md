# Changelog

## 1.0.0 — Free Edition

- First public free-to-use encoded distribution of the email-only module.
- Uses the qualified email verification implementation from version 1.0.0.
- Identifies the Free Edition in native addon metadata and administrator output;
  removes a stale release-candidate label.
- Re-encodes runtime PHP for PHP 8.1/8.2/8.3; language catalogs and template stay editable.
- Distributes only the required email runtime, license and customer documentation.
- SMS code, old candidates, commercial sales drafts, tests, build/encoder tools,
  credentials and internal deployment material are excluded.
- No feature updates, personal support or upgrade to v2.0.0 is included.
